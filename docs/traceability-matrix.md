## Ghi chú

- Tên test là tệp/phạm vi kiểm thử hiện có, không phải mã test case được khai báo riêng trong Jest/Vitest.
- API integration tests dùng mock hoặc DB in-memory; không chứng minh PostgreSQL thật, concurrency thực, payment gateway thật, browser E2E hoặc Production.
- [Use case checkout](./requirements/use-case-checkout.md) mô tả `POST /promotions/validate`, nhưng hiện thực áp khuyến mãi khi tạo đơn. Tài liệu Task 1.2 được cung cấp ghi FR-10 tích điểm khi đơn hoàn tất; SRS trong repository ghi `PAID`, còn code tích điểm khi thanh toán thành công. Cần thống nhất yêu cầu nguồn trước nghiệm thu.
- NFR-04 chưa được chứng minh hoàn tất: Compose chỉ khai báo DB, API chưa có `GET /health`, và chưa có URL Production hoạt động được xác minh. Cấu hình workflow không thay thế việc deploy và kiểm tra URL thực tế.
- Quy tắc chấm mục 8.1 yêu cầu artifact ở task trước phải tồn tại để được tính truy vết; bảng chỉ liên kết artifact tìm thấy.
